# MOOK — образовательная платформа

Учебный итоговый проект, практическая работа №9.

Откройте index.html в браузере или запустите `python -m http.server 8080`.
Шесть страниц: главная, о платформе, курсы, расписание, урок с тестом, контакты.
Технологии: HTML5, CSS3, JavaScript. Без внешних библиотек и установки зависимостей.
Фильтр курсов, мобильное меню, тест и формы работают в браузере.
Формы демонстрационные: не создают аккаунты и не отправляют сообщения.
Иллюстрации и видео созданы для этого учебного проекта.
