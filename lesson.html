Из чего состоит веб-страница?

Разберём три слоя сайта и проверим знания в небольшом тесте.

HTML задаёт структуру

Заголовки, абзацы, изображения и ссылки описываются тегами. Семантические теги подсказывают назначение блоков: header – шапка, main – основное содержимое, footer — подвал.

<main>
  <h1>Мой первый сайт</h1>
  <p>Я изучаю HTML.</p>
</main>

Один главный заголовок h1 помогает понять тему страницы. Для изображений укажите alt, а для документа – lang="ru".

CSS отвечает за оформление

CSS задаёт цвет, шрифт и расположение элементов. Свойство display: grid строит двумерную сетку, а display: flex располагает элементы вдоль одной оси.

Переход transition делает изменение плавным; transform позволяет перемещать, вращать и масштабировать элемент.

JavaScript добавляет поведение

Событие click сообщает о нажатии, а addEventListener связывает его с функцией. Через textContent можно безопасно изменить текст элемента.

button.addEventListener('click', function () {
  text.textContent = 'Готово!';
});
